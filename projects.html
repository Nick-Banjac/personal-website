Merlin Map Scanner
Custom built React-Native Android app for iData PDE barcode scanning devices in hospital pharmacies. Captures script and medication chart images, and handles stock operations (imprest requisitions, purchase orders, stocktakes), uploading to a MerlinMAP server via a digitally-signed REST API with an offline retry queue and SFTP support for supply-only sites.
Client based product
